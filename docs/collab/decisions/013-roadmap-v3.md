# 013 — Решения по ревью ROADMAP v3

От: Claude · Утвердил: Андрей («прочитай и приступай к фазе 9») · Применено в `docs/ROADMAP.md` (v3.1) и в фазе 9

## Замечания
| № | Решение |
|---|---|
| 1 | **Принято.** Простая вода — уже в фазе 9: `Tile.WATER`, река при создании нового города (шум, по зерну), дорога через воду = мост (`road-bridge.glb`) дороже обычной; на воде нет зон, зданий и деревьев. Большие карты, стоки и ресурсы — в фазе 17. Старые сохранения остаются без воды. |
| 2 | **Принято частично.** Карточка «Инфо» по клику (без инструмента в руке) — в фазе 9: стоимость земли, загрязнение, шум, жители / работа, свет, вода. Формула **счастья** — в фазе 10 вместе с уровнями (там же она нужна для роста уровня); карточка её покажет. |
| 3 | **Принято.** Типы дорог — сразу после плотности (новая фаза 11); образование — фаза 12. Проспект открывается званием. |
| 4 | **Принято.** Слои не сохраняются — пересчитываются по городу (как свет, вода, трафик). Три слоя `PackedByteArray` 0..100: `pollution`, `noise`, `land_value` (без деления на воздух и землю). Счёт: источники → двойное скользящее окно по X и по Y. Когда: при смене `buildings_version` / `roads_version` (сразу и на паузе) и вместе с трафиком (раз в 5 тиков). |
| 5 | **Принято для фазы 10:** плотность — новые значения `CityGrid.Zone` (0..3 не меняются, старые сохранения читаются без миграций), `zone_category()` / `zone_density()`, перекраска плотности поверх домов; уровень — `BuildingData.density` / `level`, повышение = смена `type_id`; цифры пропорциональны на жителя. |
| 6 | **Принято для фазы 13:** транзитные рёбра в том же Дейкстре. |
| 7 | **Принято для фазы 14:** потоки, без агентов; радиус служб по времени проезда. |
| 8 | **Принято:** круглые тупики и «зебры» — в фазу 19 (живые детали), кольцо 2×2 — в фазу типов дорог. Диагонали — нет. |
| 9 | **Принято:** образование в 2 ступени; специализации промзоны — через политики и палитры; **стройплощадка** при росте и повышении уровня — в фазу 10; «чистая» промзона 3-го уровня — в фазу образования. |
