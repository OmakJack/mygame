# 011 — Решения по ревью визуальной фазы В1

От: Claude · Утвердил: Андрей · Применено в ветке `visual-pass`

## Замечания
| № | Решение |
|---|---|
| 1 | **Частично.** Замер: 235 из 263 моделей — одна часть, склейка зданиям почти ничего не даёт; машины — 5–7 частей. Принято: склейка частей с одним материалом в одну поверхность (`SurfaceTool.append_from`), машины без теней, у солнца 2 ступени теней (PSSM 2), каждая модель загружается один раз. |
| 2 | Принято: общий масштаб на набор — дома 1.1, магазины 1.4, цеха 1.0 (с прежним пределом основания 1.8 м). |
| 3 | Принято: модели служб и многоэтажки не растут сами — новое поле `BuildingData.grows` (типы остаются в каталоге: на них могут ссылаться сохранения; многоэтажки — задел под уровни зданий). Одинаковые цифры внутри зоны — оставлены; правило «сохранять среднее по зоне» — для будущих разных цифр. |
| 4 | Принято: вывеска ставится на реальную крышу в точке крепления (по вершинам модели). Пожарная часть — `industrial/building-l` (без трубы), поликлиника — `commercial/building-n` с вывеской-крестом. |
| 5 | Принято: повороты дорог — таблица `MODEL_TURNS`; распознавание рукавов по геометрии — только в тесте. |
| 6 | Принято (ошибка в комментарии): полиция ≈ 3 % машин (вес выбора); добавлены `sedan-sports`, `suv-luxury`. |
| 7 | Принято: рассеянный свет 0.5, тон ACES, `shadow_bias` 0.03, `shadow_normal_bias` 1.2; под построенными домами плашка зоны почти прозрачная, высота зон ниже; мягкий край карты (`smoothstep`); **деревья** на пустых клетках и вокруг карты (рощи по шуму, исчезают при стройке). |

## Отложено
Припаркованные машины служб у фасадов; разные цифры для больших и маленьких домов (с сохранением среднего по зоне).
