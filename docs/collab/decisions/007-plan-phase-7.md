# 007 — Решения по ревью плана фазы 7

От: Claude · Утвердил: Андрей · Применяется в ветке `phase-7-save-load`

## Замечания
| № | Решение |
|---|---|
| 1 | **Отклонено после проверки.** `DirAccess.rename_absolute` поверх существующего файла в Godot 4.7.2 на Windows вернул `OK`, содержимое заменилось (тест в scratchpad). Схема с `.bak` не нужна: `.tmp` → rename. |
| 2 | Принято: камера не двигается, пока фокус в `LineEdit` / `TextEdit`; окно сохранений ставит паузу и выключает инструмент. |
| 3 | Принято (проверено: `JSON.parse_string("{\"id\": 1}")` → `1.0`): явные `int(...)`, `StringName(...)`; здания по возрастанию `id`; `next_building_id` ≥ max(id) + 1. |
| 4 | Принято, но мягче: всё происходит в одном кадре, мигания нет; метода `is_connected_to_city` у нас нет. `Simulation` переносится в сцене выше визуализаторов. |
| 5 | Принято: автосохранение только если есть дороги или здания. |
| 6 | Принято: очистка имени файла, проверка байтов зон и дорог; дороги — байт на клетку, без битовой упаковки. |

## Формат
- `meta.name` — принято.
- `meta.seed` — **не сейчас**: рост недетерминирован, сид не на что применить.
- `w` / `h` / `style` в зданиях — **не пишем впрок**. Вместо этого закреплено правило: незнакомые поля пропускаются, отсутствующие берутся по умолчанию — это и есть задел под CityRT и фазу 8.
- Ключи координат — `x`, `y` (как в `CityGrid`), не `x`, `z`.

## Остальное
`SaveManager` — автозагрузка; одно автосохранение без ротации; новый город — новый объект `CityGrid`.
