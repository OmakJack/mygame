# 003 — Решения по ревью Argon

От: Claude · Утвердил: Андрей · Применяется в ветке `phase-5-economy-ui`

## Вопросы
1. `upkeep` зданий — **не списывается** (как в SimCity: город платит за дороги и службы, дома содержат себя сами). Поле остаётся для служебных зданий фазы 6.
2. Снос — **бесплатный**, снятие зоны тоже.

## Замечания
| № | Решение |
|---|---|
| 1 | Принято. `simulation.gd` пересчитывает статистику и шлёт `stats_changed` и по `cells_changed` / `grid_reset` вне тика; флаг «идёт тик» от двойного пересчёта. |
| 2 | Принято. Кэш отсортированного списка и списков по зонам; пустой `id` — ошибка. |
| 3 | Принято, менять нечего. Пересчёт спроса между сносом и ростом в одном тике — не нужен. |

## Предложения по фазе 5
| Предложение | Решение |
|---|---|
| Темп роста 1 дом на зону за тик | Принято. |
| Старт 2000 $, дорога 10 $, зона 5 $, снос/снятие 0 $ | Принято. |
| Налог 9 % (0–20 %), содержание дорог 0.2 $/клетка/день | Принято. |
| Налоговый множитель 0.05, `upkeep` зданий списывается | **Изменено.** С 0.05 тестовый город даёт 252 $/день (= секунду), квартал из 66 зданий (~1500 $) окупается за 6 с — деньги перестают ограничивать через минуту. Множитель 0.05 был нужен, чтобы магазины окупали своё содержание. Решение: здания без содержания, множитель **0.01** → тестовый город ≈ +43 $/день, квартал окупается за ~35 с. |
| Налоговая поправка спроса 0.08 на 1 % от 9 % | Принято. |
| Деньги < 0: без банкротства, платное строительство до остатка денег, превью показывает только доступное | Принято. |
| UI: `hud.tscn`, верхняя/нижняя панель, `mouse_filter` | Принято. Кнопки инструментов и скорости — кодом из таблицы; у всех кнопок `focus_mode = NONE` (иначе Пробел жмёт кнопку). |
| Сигналы `tool_requested`, `tool_mode_changed`, `speed_changed` | Принято, плюс `tax_rate_requested(rate)` — UI не меняет `GameState` напрямую. |
| Курсор над UI: `gui_get_hovered_control`, протягивание не обрывается | Принято. |
