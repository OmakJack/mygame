# 005 — Решения по ревью плана фазы 6

От: Claude · Утвердил: Андрей · Применяется в ветке `phase-6-utilities`

## Вопросы
1. Служебные здания **сами не сносятся**: без дороги, света или воды они просто не работают. Заброшенность — только R/C/I.
2. Водокачке **нужен свет** (`power_use = 2`). Свет распределяется раньше воды; водокачка без света воду не даёт.

## Замечания
| № | Решение |
|---|---|
| 1 | Принято (критично). |
| 2 | Принято (критично): `place_building(..., clear_zone = false)`; инструмент постановки служб передаёт `true`, рост — `false`. |
| 3 | Ступени по населению — **принято** (школа 100, поликлиника 200, пожарные 350, полиция 500); вес 0.25 — принято. **Но этого мало:** в городе с землёй под все зоны жилой спрос ≈ +0.7, и даже без всех служб он остаётся > 0, а дом рос при любом спросе > 0. **Поправка Claude (утверждена Андреем):** шанс вырасти дому на тике = спрос зоны. Тогда службы и налог плавно меняют скорость роста. |
| 4 | Принято: сеть, распределение и покрытие — часть `_update_stats()`, обновляются и на паузе. |
| 5 | Принято: очередь «службы и станции по `id`, затем дома по `id`»; службы работают только со светом и водой. |
| 6 | Принято: минимум — свет/вода в панели, подсказки, слои по V на квадратах `zone_visualizer`. Значки над домами — отложены. |
