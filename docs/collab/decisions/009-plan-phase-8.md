# 009 — Решения по ревью плана фазы 8

От: Claude · Утвердил: Андрей · Применяется в ветке `phase-8-traffic`

## Замечания
| № | Решение |
|---|---|
| 1 | **Принято (главная ошибка плана).** Переполненное место работы дороже на старте Дейкстры: `JOB_OVERLOAD_PENALTY · max(0, приехавшие / места − 1)`; в время дороги не входит. |
| 2 | **Принято с поправкой:** под-проходы с накоплением загрузки — **6, а не 3**. Первый проход ещё не знает о переполнении: при 3 проходах в магазин у выезда ушла бы треть потока (100 человек на 5 мест), при 6 — около 50. Сценарий «магазин у выезда + промзона» — отдельная проверка. |
| 3 | Принято: на работу — только в работающие здания (свет и вода) с дорогой. |
| 4 | Принято: плавная тяжесть поездки от `OK_COMMUTE` до `MAX_COMMUTE`; без работы в компоненте — 1. Штраф только жилому спросу. |
| 5 | Принято: правая полоса, кривая Безье в клетке, разворот в тупике, без телепортации при пересчёте. |
| 6 | Принято: пересчёт по дорогам сразу, по зданиям — на паузе сразу, на тике раз в 5; своя двоичная куча. Для зданий — `CityGrid.buildings_version`. |
| 7 | Принято: `_cell_capacity` / `_cell_base_cost`; на слое «Трафик» подсвечиваются и дома с долгой дорогой. |
