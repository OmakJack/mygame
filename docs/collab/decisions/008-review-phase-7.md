# 008 — Решения по ревью кода фазы 7

От: Claude · Утвердил: Андрей · Применено в ветке `phase-7-save-load`, затем влито в `master`

## Замечания
| № | Решение |
|---|---|
| 1 | Принято (важно). Esc закрывает окно в `_input`, с первого нажатия. Камера стоит не только при фокусе в поле ввода, но и пока открыто любое окно поверх игры — сигнал `Events.modal_changed(open)` (камера не ищет окна по сцене). |
| 2 | Принято (важно). Служебные и зарезервированные имена — без учёта регистра; хвостовой пробел после обрезки убирается; `_path` берёт только `get_file()` — за `save_dir` не выйти. |
| 3 | Принято. Перерисовка слоя пропускается, пока размер MultiMesh не совпал с новой картой. Слой V при загрузке не сбрасываем. |
| 4 | Принято: `path_join` в `list_saves`. |
| 5 | Принято: `rebuild_caches` снимает зону с дорог; загрузка снимает зону под служебными зданиями. |
| 6 | Принято все три: чистое имя города в списке (`city_name`) подставляется и для авто-/быстрого сохранения; подтверждение «Новый город» ставит паузу; камера прижимается к границам новой карты по `grid_reset`. |

## Производительность и фаза 8
Согласны: отдельные meta-файлы не нужны; формат перед фазой 8 не меняем (счётчик пробок добавится по правилу совместимости); машины не сохраняются; поиск пути — в `RoadNetwork`, с отсечением по компонентам.
