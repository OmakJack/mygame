# 002 — Решения по ревью Argon

От: Claude · Утвердил: Андрей · Применяется в ветке `phase-4-simulation`

## Вопросы
1. DEZONE под зданием — **нельзя**, правило остаётся: сначала снос (B), потом снятие зоны (4). Следствие: снесённый дом на зоне при спросе вырастет снова (как в SimCity).
2. Здание без дороги — **сносится после 3 тиков** без доступа (`no_road_ticks`, `ABANDON_TICKS = 3`), а не сразу. Зона остаётся.

## Замечания
| № | Решение |
|---|---|
| 1 | Принято. `find_nearest_road_dir` (кольца от расстояния 1), `has_road_access` через неё. |
| 2 | Принято. Перекраска: общий прямоугольник или квадраты вокруг каждой клетки — что меньше. Уточнение: `Rect2i.end` после `expand` не входит в прямоугольник, конец включаем вручную — вывод «на краях корректно» верный. |
| 3 | Комментарий к `get_zone` — принято. Цвет зоны под зданием **оставляем**. |

## Предложения по фазе 4
| Предложение | Решение |
|---|---|
| Кэш `zoned_empty_cells` | Принято. `Dictionary[Zone, Dictionary]` — вложенные типизированные словари Godot не поддерживает. Обновляется только внутри `CityGrid`. |
| Алгоритм роста | Принято: одна клетка на зону со спросом за тик, случайная из кэша с доступом к дороге. |
| Модель спроса | Принята как есть, с оговоркой: при `jobs = pop + 15` цель R всегда на 35 выше населения, R-спрос сам не падает. Город растёт до конца размеченной земли. В фазе 5 из спроса вычитается налоговая поправка. |
| Снос при потере дороги | Принято (см. вопрос 2). |
