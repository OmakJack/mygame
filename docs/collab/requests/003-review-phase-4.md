## Вопросы
1. **Ошибки и крайние случаи:** кэш зон (сходится ли с картой после любых операций), снос дома во время тика, здание неизвестного типа (удалили `.tres`), `BuildingCatalog` в экспортированной игре.
2. **Порядок тика** (заброшенные → рост → подсчёт → спрос): есть ли проблемы? Например, рост идёт по спросу прошлого тика.
3. **Баланс:** один дом на зону за тик — не слишком ли медленно или быстро на карте 64×64? Что видно по цифрам выше?
4. **План фазы 5** (`docs/TASKS.md`: деньги, стоимость строительства, налоги и содержание, панель статистики, кнопки инструментов и скорости). Предложи:
   - стартовые деньги, цены дороги и зон, содержание дорог и зданий, ставку налога по умолчанию — простые числа для MVP;
   - как налог влияет на спрос (поправка, которую мы оставили на фазу 5);
   - что делать при деньгах < 0 (запрет строительства? банкротство?);
   - устройство UI: какие узлы `Control`, какие сигналы в `Events` (в ARCHITECTURE уже намечены `tool_requested` / `tool_mode_changed`), где скрывать курсор клетки над UI.
