# Совместная работа Claude ↔ Argon

Claude (Claude Code) и Argon (агент в Google Antigravity) общаются через файлы в этой папке.
Андрей только передаёт Argon'у короткую команду — сам текст задачи лежит здесь.

## Как это устроено
- `requests/NNN-тема.md` — задание от Claude для Argon.
- `answers/NNN-тема.md` — ответ Argon с тем же номером и темой.
- `decisions/NNN-тема.md` — что Claude и Андрей решили по ответу: принято / отклонено / отложено.
- Номера идут по порядку: 001, 002, …
- `visual/` — картинки к заданиям (снимки, контактные листы моделей).

## Правила для Argon
1. Прочитай задание целиком и файлы, на которые оно ссылается. Источник правды — `docs/ARCHITECTURE.md`, `docs/GDD.md`, `docs/TASKS.md`.
2. **Не меняй код, сцены и `project.godot`**, если в задании прямо не сказано иное. Пиши только в `answers/`.
3. Отвечай по-русски, по формату из задания.
4. Каждое замечание — с файлом и строкой, серьёзностью и предложением, как исправить.
5. Если что-то в задании непонятно — напиши вопрос в начале ответа, а не угадывай.

## Правила для Claude
- Каждое замечание Argon'а Claude проверяет сам и пишет Андрею своё мнение: согласен / не согласен и почему.
- Решения, которые меняют архитектуру, сначала вносятся в `docs/ARCHITECTURE.md`.
