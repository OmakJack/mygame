# Архитектурный Low-Poly пак зданий (Blender 5.2)

Готовый набор из **48 детализированных low-poly зданий** (жилые дома, офисы и заводы) на участках **1×1, 2×1, 3×1, 4×1, 5×1, 7×1, 2×2 и 3×2 клетки**.
Модели пока **не подключены в код игры** — они полностью подготовлены под конвенции проекта (`ModelLoader`, `BuildingPalette`, `LotPlanner`, `generate_building_types.gd`) для быстрой интеграции.

---

## Структура папки

- `assets/models/blender/pack/residential/*.glb` — **18 жилых зданий** (`RESIDENTIAL` и `RESIDENTIAL_HIGH`, ур. 1–3)
- `assets/models/blender/pack/offices/*.glb` — **15 офисных зданий и бизнес-центров** (`OFFICE`, ур. 1–3)
- `assets/models/blender/pack/industrial/*.glb` — **15 заводов и промкомплексов** (`INDUSTRIAL`, ур. 1–3)
- `assets/models/blender/pack/manifest.json` — машиночитаемый реестр всех 48 моделей (пути, размеры в клетках и метрах, число вершин/треугольников, рекомендуемые зоны и уровни)
- `assets/models/blender/pack/previews/` — 4 отрендеренных контактных листа (Blender EEVEE):
  - `pack_showcase.png` — общая диорама квартала с тремя улицами
  - `pack_residential.png` — все 18 жилых зданий по размерам участков
  - `pack_offices.png` — все 15 офисных зданий по размерам участков
  - `pack_industrial.png` — все 15 промышленных объектов по размерам участков

Генераторы на Python для Blender 5.2 лежат в `tools/blender/`:
- `tools/blender/arch_kit.py` — архитектурный конструктор (`ArchBuilder`: плавные АО-градиенты по палитре Kenney, скатные/вальмовые/мансардные/шедовые/арочные крыши, слуховые окна, балконы, навесные стеклянные фасады, восьмигранные башни, градирни, козловые краны, гелипады, HVAC и солнечные панели)
- `tools/blender/pack_residential.py` — 18 генераторов жилых домов
- `tools/blender/pack_offices.py` — 15 генераторов офисов
- `tools/blender/pack_industrial.py` — 15 генераторов заводов
- `tools/blender/make_building_pack.py` — пакетная сборка `.glb`, `manifest.json` и рендер превью-листов

## Технические параметры для интеграции в Godot (памятка для Claude)

1. **Масштаб и сетка (`model_scale = 1.0`):**
   - Модели построены сразу в игровом масштабе `CityGrid.CELL_SIZE = 2.0` м на клетку.
   - Центр участка `(0, 0)`, подошва здания строго на высоте `0.0`.
   - Габариты каждого здания выдержаны с аккуратным отступом от края участка (`~1.70×1.72` м для `1×1`, `~3.74×1.74` м для `2×1`, `~5.74×1.74` м для `3×1`, `~7.74×1.76` м для `4×1`, `~9.74×1.76` м для `5×1`, `~13.74×1.76` м для `7×1`, `~3.74×3.76` м для `2×2`, `~5.76×3.76` м для `3×2`).

2. **Ориентация фасада (`model_turns = 2`):**
   - В Blender главный уличный фасад (крыльцо, витрины, колоннады, арки, погрузочные доки) смотрит на **`-Y`**.
   - При экспорте glTF (`+Y up`) `-Y` переходит в `+Z` в Godot, поэтому как у `res_panel_*` и `make_large_buildings.py` нужно ставить **`model_turns = 2`** (поворот на 180°, главный фасад встанет к дороге на **`-Z`**).

3. **Пути в `tools/generate_building_types.gd`:**
   - Функция `_model_path(relative)` уже резолвит префикс `"blender/"` в `"res://assets/models/" + relative + ".glb"`.
   - Достаточно передавать `godot_kit_path` из `manifest.json`, например:
     `"blender/pack/residential/res_nordic_cottage_1x1"`, `"blender/pack/offices/off_diagrid_needle_1x1"`, `"blender/pack/industrial/ind_thermo_plant_3x2"`.

4. **Один меш и полная совместимость с `BuildingPalette`:**
   - Каждый `.glb` содержит ровно **1 меш-примитив** и **1 материал** на текстуре `res://assets/models/kenney/suburban/Textures/colormap.png` (`8×4` ячеек).
   - UV разложены по правой градиентной половине ячеек (`u = (col + 0.75) / 8`, `v` строго внутри `[row + 0.22 .. row + 0.76] / 4` без протечки соседних ячеек на mip-уровнях).
   - Шейдер `BuildingPalette.SHADER` корректно перекрашивает по районам основные стены `(3, 2)` / `(7, 2)` и акцентные крыши `(0, 1)` / `(6, 1)` / `(1, 3)`, оставляя нетронутыми голубое остекление `(4, 1)` / `(5, 1)`, кирпич, терракоту, дерево, медь, сталь и бетон.

5. **Примечание про участки `4×1`:**
   - Помимо стандартных размеров `1×1, 2×1, 3×1, 5×1, 7×1, 2×2, 3×2`, в каждую категорию добавлена модель **`4×1`** (`res_stalin_block_4x1`, `off_skybridge_gate_4x1`, `ind_assembly_plant_4x1`). При регистрации зданий `Vector2i(4, 1)` в каталоге `LotPlanner` сможет выделять цельные участки `4×1` вдоль улицы без принудительной разрезки `4 → 2 + 2`.

## Пересборка пака в Blender 5.2

Если понадобится подправить размеры, цвета или добавить модели, весь пак и 4 превью-листа пересобираются одной командой без окна (~25 сек):

```powershell
& "C:/Program Files/Blender Foundation/Blender 5.2/blender.exe" --background --factory-startup --python tools/blender/make_building_pack.py
```
